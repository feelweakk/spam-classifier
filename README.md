# 📩 Spam Classifier

Модель машинного обучения для определения спама в SMS сообщениях.

## 📊 Результаты
- Точность: 96.68%
- Алгоритм: Naive Bayes + TF-IDF

## 🛠 Технологии
- Python
- pandas
- scikit-learn

## 🚀 Запуск
```bash
pip install pandas scikit-learn nltk matplotlib seaborn
python spam.py
```

## 📁 Датасет
SMS Spam Collection Dataset — 5572 сообщения (4825 ham + 747 spam)
